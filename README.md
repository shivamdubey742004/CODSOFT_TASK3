# Customer Churn Prediction

## Project Overview
This project predicts whether a customer is likely to leave a company or continue using its services using Machine Learning.

## Objective
To analyze customer data and identify customers who are likely to discontinue a service.

## Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Machine Learning Algorithms
- Logistic Regression
- Random Forest
- Gradient Boosting

## Project Workflow
1. Load the customer dataset.
2. Perform data cleaning and preprocessing.
3. Explore and visualize the data.
4. Train Machine Learning models.
5. Evaluate model performance.
6. Predict customer churn.

## How to Run
Open the `.ipynb` notebook in Google Colab or Jupyter Notebook and run the cells.
